# BIMED New Starter Onboarding Checklist

**Employee:** [NAME]  
**Role:** [ROLE]  
**Start date:** [DATE]  
**Manager:** [NAME]

## Before first shift

- [ ] Employment documentation complete.
- [ ] Identity and required checks complete.
- [ ] Work eligibility / permit status recorded where applicable.
- [ ] Required credentials recorded.
- [ ] Staff profile created and BIMED staff number issued.
- [ ] Staff portal activation completed.
- [ ] Work email/contact details confirmed.
- [ ] Rota access confirmed.
- [ ] Attendance access confirmed.
- [ ] Payroll information collected through the approved secure process.
- [ ] Mandatory training plan assigned.

## Day 1

- [ ] Welcome and introduction completed.
- [ ] Workplace/service tour completed.
- [ ] Manager/supervisor introduced.
- [ ] Safeguarding and escalation routes explained.
- [ ] Confidentiality and information-security expectations explained.
- [ ] Infection prevention and health/safety arrangements explained.
- [ ] Emergency arrangements explained.
- [ ] Care plans/documentation standards explained.
- [ ] Questions recorded.

## Week 1

- [ ] Required induction modules completed.
- [ ] Role-specific competencies reviewed.
- [ ] Shadowing/supervision completed where applicable.
- [ ] Attendance records reviewed.
- [ ] Rota understood.
- [ ] Leave and sickness reporting process understood.
- [ ] First supervisor check-in completed.

## First month

- [ ] Outstanding compliance items reviewed.
- [ ] Mandatory credentials/training status reviewed.
- [ ] Performance and support check-in completed.
- [ ] Any concerns escalated and documented.
- [ ] Employee confirms understanding of key policies.
