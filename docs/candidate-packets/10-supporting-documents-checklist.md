# BIMED Supporting Documents Checklist

**Candidate:** [NAME]  
**Role:** [ROLE]  
**Pathway:** [IRELAND / INTERNATIONAL]

Use this checklist only as an indication of documents BIMED may request. The recruitment team should issue the final candidate-specific list.

## Identity

- [ ] Passport / approved identity evidence.
- [ ] Current address evidence where requested.
- [ ] Relevant immigration permission evidence, where applicable.

## Employment and experience

- [ ] Current CV.
- [ ] Previous employment details.
- [ ] Reference details.
- [ ] Employment/reference evidence requested by BIMED.

## Qualifications and registration

- [ ] Qualification certificates.
- [ ] Professional registration/licence, where the role requires it.
- [ ] Training certificates relevant to the role.
- [ ] Credential verification information requested by BIMED.

## International employment

- [ ] Work-permission information.
- [ ] Employment-permit information/evidence requested for the applicable process.
- [ ] Relocation information.
- [ ] Candidate sponsorship information requested by BIMED.

## Role-specific evidence

- [ ] Additional safeguarding/vetting information where applicable.
- [ ] Occupational or fitness documentation where law/policy requires it.
- [ ] Any other evidence specifically requested for the role.

## Submission rules

Use only the secure submission route provided by BIMED. Do not send passwords, PINs, authentication codes, or banking credentials. Keep your own secure copies of documents you submit.

BIMED should record whether each requested document is **received**, **pending review**, **verified**, **rejected**, or **expired**, and should communicate clearly when a replacement is required.
