# BIMED Candidate Document Pack

This directory contains the controlled source documents used for shortlisted candidate communication and onboarding.

## Pack structure

### Recruitment pack
1. `01-role-information-pack.md` — role, duties, expectations, working pattern, and recruitment notes.
2. `02-interview-questionnaire.md` — structured interview questionnaire for support workers and healthcare workers.
3. `03-candidate-application-guide.md` — instructions for completing the private application and supplying evidence.
4. `04-visa-sponsorship-application-pack.md` — international candidate immigration and sponsorship information/checklist.

### Offer and onboarding pack
5. `05-employment-contract-template.md` — BIMED employment contract source template. HR/legal approval is required before issue.
6. `06-welcome-to-ireland-pack.md` — practical pre-arrival and arrival information for overseas hires.
7. `07-care-in-ireland-handbook.md` — care-work orientation, professional conduct, safeguarding, communication, and first-week expectations.
8. `08-international-relocation-checklist.md` — candidate checklist from offer acceptance through first month in Ireland.

## Controlled-content rule

These are source templates. Any legal, immigration, employment, safeguarding, payroll, or regulatory wording must be reviewed and approved by BIMED before production use. The portal must not represent these documents as legal or immigration advice.

## Routing

- Ireland-based candidates: recruitment correspondence uses `recruitment@bimedhealthcare.com`.
- International candidates: recruitment correspondence uses `overseas@bimedhealthcare.com`.
- Automated internal portal notifications remain routed to `info@bimedhealthcare.com`.

## Personalisation

The portal should populate candidate-specific fields only after a document has been approved for issue. Typical variables include candidate name, role, employment start date, location, salary/working pattern, BIMED contact details, and sponsorship status.
